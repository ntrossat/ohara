# Configure

Ohara has one setting, `OHARA_URL`. Everything else is configured in GitHub:

| What | Where | Page |
|---|---|---|
| Pages, menu, and freshness | Markdown files and front matter in the docs repository | [Docs repository](docs-repository.md) |
| Folders that need review | `CODEOWNERS` in the docs repository | [Docs repository](docs-repository.md#review-rules) |
| Code that flags pages, docs that merge with code, docs that sync from code | The GitHub App's installation, and `.ohara.yml` in code repositories | [Code repositories](code-repositories.md) |
| Who can read | The docs repository's visibility and collaborators | [Access](access.md) |
